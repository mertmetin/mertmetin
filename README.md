### Hi, I'm Mert 👋

Software engineer in **Ottawa** who builds things people use every day: full-stack web apps, mobile apps, data pipelines and AI automation. My thesis at the **University of Ottawa** was on machine learning for social media geolocation.

I also run a real-estate practice, and most of my recent work is the software behind it: production systems with real users, real data and real money moving through them.

#### 🔭 Featured

- **[Geolocation-Prediction](https://github.com/mertmetin/Geolocation-Prediction):** my uOttawa thesis, rebuilt in 2026. Predicts where Canadian Twitter users live from their tweets (61% within 161 km) and their social graph (88%). I found and fixed 7 bugs in the original research code, moved it to a stricter evaluation, and added a web demo with a map.
- **[productsearch](https://github.com/mertmetin/productsearch):** my 2014 Django + Elasticsearch product search, rebuilt as an evaluated search engine. Keyword, semantic and hybrid retrieval scored on 480 human-labelled queries: hybrid search improves NDCG@10 from 0.706 to 0.772. FastAPI web app with facets and a 2014 vs 2026 side-by-side view.
- **Rabbit:** an on-demand delivery platform with a customer app, a driver app and a backend. React Native (Expo) apps, a Next.js + Prisma API, Stripe payments, push notifications and photo proof of delivery. *Private; happy to walk through it.*
